# Decision records

Five decisions that were real trade-offs: hard to reverse, surprising
without the context, and made against an alternative I had a reason to
reject. Each record names the downside I accepted, not only the benefit.

Choices that were never trade-offs are not recorded here. Padding this
directory with "we chose Python" would bury the five that matter.

| [0001](0001-one-engine-for-lexical-and-vector.md) | One search engine serves both lexical and vector retrieval |

| [0003](0003-tables-attach-to-the-document.md) | Table chunks attach to the document, not to their section |
| [0004](0004-rest-not-rpc.md) | REST serving layer rather than RPC |
